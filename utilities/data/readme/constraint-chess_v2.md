# Constraint Chess - Developer Documentation

Constraint Chess is an interactive application module within the portfolio.

## Architecture & Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript.
- **Styling**: Component-specific and shared CSS.

## Key Systems / Components
- Core rendering logic in entry file.
- Event-driven UI updates.

## Performance & Accessibility
- Focus on local, zero-latency feedback.
- Semantic HTML for screen readers.

## Integration & DB
- Client-side state only (no persistent DB).
