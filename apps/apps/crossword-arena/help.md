# Crossword Arena — User Guide

Crossword Arena contains five original weekly puzzles, two library puzzles, and an unlockable Meta puzzle. Progress and statistics remain on the current device.

## Playing

1. Select a puzzle from the Library.
2. Select a grid cell.
3. Type letters on a physical keyboard or use the mobile keyboard that opens after tapping the grid.
4. Use arrow keys to move.
5. Use Tab or the Across/Down buttons to change direction.
6. Double-tap the same cell on mobile to change direction.
7. Solve all five weekly puzzles to unlock the Meta.

## Assistance

- **Check** reports empty or incorrect cells.
- **Reveal letter** fills the selected cell.
- Using Check or Reveal marks the completion as assisted.
- Only clean completions are eligible for the clean best-time statistic.

## Offline use

Install the game through the browser’s PWA installation option. After the application shell and puzzle pack have cached successfully, the game can load offline.

## Troubleshooting

- Reload the page if a newly deployed version has not appeared.
- Confirm that browser storage is allowed if progress does not save.
- Tap a grid cell again if the mobile keyboard closes.
- Clear only the Crossword site data when intentionally resetting all local progress.
