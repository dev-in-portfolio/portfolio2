# Oracle Pit - User Guide

Oracle Pit (The Council of Chaos) is an interactive cyberpunk-themed application where users consult simulated AI oracles for cryptic advice and predictions.

## Features
- Immersive cyberpunk visual design.
- Interactive terminal-style interface.
- Cryptic, generative text responses from the "Council".
- Atmospheric grid and gradient backgrounds.

## Step-by-Step Usage
1. Launch the Oracle Pit application.
2. Read the introductory text in the terminal window.
3. Type your query or select a prompt to present to the Council.
4. Watch as the application generates a styled, simulated response.
5. Experiment with different inputs to uncover unique lore and responses.

## Troubleshooting
- If the text doesn't appear properly, ensure custom fonts (Space Grotesk, JetBrains Mono) are not blocked by your network.
- If the terminal stops responding, hit enter or refresh the page to restart the session.
- Visual glitches can often be resolved by resizing the browser window.
