# SleepyStory Studio - User Guide

SleepyStory Studio is an enchanting "Magic Bedtime Adventures" app designed to generate or display bedtime stories in a visually appealing, book-like interface.

## Features
- Magic book interface with a paper-texture background.
- Engaging typography and child-friendly aesthetics.
- 3D perspective elements.

## Step-by-Step Usage
1. Open the SleepyStory Studio application.
2. Navigate through the interface to select or generate a bedtime story.
3. Read the story presented on the "paper" background.
4. Use the on-screen navigation to flip through stories or scenes.

## Troubleshooting
- If text is difficult to read, ensure your browser is not overriding the custom fonts (Quicksand, Fredoka One).
- Visual glitches (like overlapping pages) can often be fixed by resizing your browser window.
- Ensure JavaScript is enabled for interactive 3D perspective features.
