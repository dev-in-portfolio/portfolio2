Local Runner

Download Runner

The runner is a small Node CLI that installs .agentpack.zip files into .agentx/, enforces directory allowlists, and emits receipts per run.

Download runner.zip Windows: coming soon Mac: coming soon Linux: coming soon

Setup

1) Unzip runner.zip 2) cd runner 3) npm install 4) node agentx.js allow /path/to/your/workspace 5) node agentx.js install /path/to/pack-a.agentpack.zip 6) node agentx.js agents

Safety model

Runner blocks file operations outside your allowlist. Agents declare required permissions. Some actions require approval flags to proceed.

What you approve

Workspace paths, pack installs, high-risk permissions, and any browser automation beyond the bundled demo targets.

What you get back

A receipt bundle with run metadata, timeline entries, logs, artifacts, screenshots when applicable, and redacted secrets.

Execution Gate

Before an agent can run

1

Manifest parsed

The pack declares agent entrypoints, required scopes, expected outputs, and demo status.

2

Policy compared

The runner checks the manifest against allowed folders, secret handles, network rules, and approval flags.

3

Receipt opened

A run bundle is created before execution so logs, artifacts, and safety events have a stable destination.
