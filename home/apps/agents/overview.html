Architecture

Platform overview

Store → Package → Local Runner → Tools → Receipts

Store (this UI) lists agents and packs. Packs are .agentpack.zip files with a manifest + agent code. Local Runner installs packs into .agentx/ and runs agents with scoped permissions. Tools are the runtime capabilities (fs, exec, browser, secrets, approvals). Receipts capture: timeline, logs, artifacts, screenshots, signatures/attestations.

Demo vs Real: This cloud UI is a demo. The actual execution happens locally via the runner. Browser agents are restricted to the demo targets shipped in this module.

Permission contract

Agents declare scopes up front. The runner compares those scopes to allowed paths, approvals, network boundaries, and secret handles before execution.

Evidence contract

Runs emit a stable receipt bundle so a human can audit what changed, which tools ran, which approvals were used, and which artifacts were created.
